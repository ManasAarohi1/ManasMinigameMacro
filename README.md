# Manas Minigame Macro

A macro that finds the watermelon in the Sol's RNG Summer event minigame.

## Requirements

- Windows
- [AutoHotkey 1.1](https://www.autohotkey.com/download/1.1/)

## How to use

1. Open Sol's RNG and join a server (a private server is better).
2. Open `ManasMinigameMacro.exe`.
3. Set the options below, then press **Start** or **F1**.
4. Press **F2** to stop.

## Settings

| Setting | What it does |
|---|---|
| Rounds | How many tickets to spend. |
| Continuous loop | Ignore Rounds and keep going until you stop it. |
| Give up after | Seconds to spend on one round before pressing Give up. |
| Auto SC + BR | Use a Strange Controller and a Biome Randomizer at the start, then every 3 rounds. |
| Click mode | Use mouse clicks instead of menu keys. Press **Calibrator** once and point at each button. |
| Auto reconnect | Rejoin your private server after a disconnect. Needs the private server link. |
| Abyssal mode | Faster paths for Abyssal Hunter, and re-equips it if a new aura replaces it. |
| UI navigation key | The key that turns on UI navigation in Roblox (default `\`). |
| Potato PC | Slower resets, menus and clicks for PCs that lag. |
| Discord webhook | Posts biomes, collected melons and problems to a Discord channel. |
| Private server link | Used for auto reconnect and in biome notifications. |
